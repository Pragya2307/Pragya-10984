Project Description

This project is a simple Password Strength Checker written in C language.
It checks whether a user-entered password is valid or invalid based on basic security rules.
The main purpose of this project is to understand string handling, loops, functions, and validation logic in C.

Purpose

This project is made to understand how password validation works in real-life applications.
Many users create weak passwords, which can lead to security issues.
This program helps check whether a password follows basic security rules.

The project is mainly created to:

Learn how to work with strings in C

Practice using loops and conditions

Understand functions and validation logic

Apply programming concepts to a real-world problem

Build a foundation for secure login systems

Features

 1. Checks minimum password length (at least 8 characters)

2. Checks presence of at least one digit (0–9)

3. Checks presence of at least one uppercase letter (A–Z)

4. Displays whether the password is VALID or INVALID
